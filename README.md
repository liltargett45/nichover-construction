Official website for **Nichover Construction Work** — quality construction, renovations, interior design and architectural services based in La, Accra, Ghana.

## Live Site
- AppDeploy (with AI features): https://nichover-construction-ai-kmny24.v2.appdeploy.ai/
- Netlify: (connect this repo in Netlify dashboard)

- Modern responsive website
- AI Quote Assistant (project description → cost range + materials checklist)
- AI Blog Helper (topic note → ready-to-publish post)
- Contact / Quote form
- WhatsApp integration

## Deploy to Netlify
1. Go to https://app.netlify.com
2. "Add new site" → "Import an existing project"
3. Connect GitHub and select this repository
4. Build command: `npm run build`
5. Publish directory: `dist`

Note: AI features currently run on the AppDeploy hosting. For full AI on Netlify you would need a separate serverless backend.
